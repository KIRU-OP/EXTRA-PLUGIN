## 🖇 VPS Deployment

<details open>
<summary><b>👉 Step-by-step (click to expand / collapse)</b></summary>

<br/>

**1️⃣ Variables lo**
Apne [necessary variables](https://github.com/vishalpandeynkp1/VIPNOBITAMUSIC_REPO/blob/master/sample.env) ready rakho.

**2️⃣ Repo clone karo**
```bash
git clone https://github.com/vishalpandeynkp1/VIPNOBITAMUSIC_REPO && cd VIPNOBITAMUSIC_REPO
```

**3️⃣ Setup chalao**
```bash
bash setup
```

**4️⃣ tmux install karo** (terminal band karne ke baad bhi bot chalta rahe)
```bash
sudo apt install tmux && tmux
```

**5️⃣ Bot start karo**
```bash
python3 -m VIPMUSIC
```

**6️⃣ tmux se bahar niklo** bina bot roke: `Ctrl + B`, phir `D`

</details>

## 🔄 Updating the Bot

<details>
<summary><b>🖥 VPS Update</b></summary>

<br/>

```bash
# 1. Bot roko (tmux attach karke Ctrl+C)
tmux attach

# 2. Latest code lao
cd VIPNOBITAMUSIC_REPO
git pull
pip3 install -r requirements.txt

# 3. Dobara start karo
python3 -m VIPMUSIC
```

</details>

<details>
<summary><b>☁️ Heroku Update</b></summary>

<br/>

1. GitHub pe apne fork mein **Sync fork** dabao.
2. Heroku dashboard → **Deploy** → **Manual deploy** → **Deploy Branch**.

</details>
