### 🖇 VPS Deployment

1. Get your [necessary variables](https://github.com/vishalpandeynkp1/VIPNOBITAMUSIC_REPO/blob/master/sample.env).
2. Clone the repo:
```bash
   git clone https://github.com/vishalpandeynkp1/VIPNOBITAMUSIC_REPO && cd VIPNOBITAMUSIC_REPO
```
3. Run the setup script:
```bash
   bash setup
```
4. Install tmux so the bot keeps running after you close the terminal:
```bash
   sudo apt install tmux && tmux
```
5. Start the bot:
```bash
   python3 -m VIPMUSIC
```
6. To leave the tmux session without stopping the bot, press `Ctrl+b`, then `d`.
